# ПРОБА — детектор дипфейков (MVP)

Веб-сервис: пользователь загружает фото → получает оценку, **сгенерировано ли оно нейросетью**
и **не подменено ли лицо (deepfake)**, с уровнем уверенности. После N бесплатных проверок —
пейволл.

Название «ПРОБА» — рабочее, замените на своё (см. `components/DetectorApp.tsx`, `app/layout.tsx`).

## Стек

- **Next.js 15** (App Router) + **React 19** + **TypeScript** — одна деплой-единица.
- Детекция — через **Sightengine** (`genai` + `deepfake` в одном запросе). Ключ живёт **только на
  сервере**, в браузер не попадает.
- Без Tailwind — рукописный CSS (`app/globals.css`).

## Быстрый старт

```bash
npm install
cp .env.example .env         # впишите ключи
npm run dev                  # http://localhost:3000
```

Ключи Sightengine — бесплатная регистрация: https://dashboard.sightengine.com/signup

## Переменные окружения

| Переменная                 | Обязательна | Назначение                                                        |
| -------------------------- | ----------- | ----------------------------------------------------------------- |
| `SIGHTENGINE_API_USER`     | да          | API user (только сервер)                                           |
| `SIGHTENGINE_API_SECRET`   | да          | API secret (только сервер)                                         |
| `QUOTA_SECRET`             | да          | Секрет для подписи cookie-счётчика. `openssl rand -hex 32`         |
| `FREE_LIMIT`               | нет         | Число бесплатных проверок (по умолчанию 10)                        |
| `NEXT_PUBLIC_CHECKOUT_URL` | нет         | Ссылка на оплату, которую открывает кнопка в пейволле              |

## Архитектура

```
Браузер ──FormData(image)──► /api/detect (сервер)
                                 │  проверяет cookie-лимит
                                 │  вызывает Sightengine (ключ на сервере)
                                 ▼
                          нормализованный результат + Set-Cookie (счётчик++)
```

- `lib/detector.ts` — провайдер-независимая `detect()`. Возвращает `{ aiGenerated, deepfake, score,
  verdict, label, generators }`.
- `lib/quota.ts` — счётчик бесплатных проверок.
- `app/api/detect/route.ts` — серверный прокси + гейт.
- `components/*` — UI: `DetectorApp` (оркестратор), `Uploader` (загрузка + сжатие), `Readout`
  (инструмент-панель), `Paywall`.

Перед отправкой картинка **сжимается на клиенте** (макс. сторона 1600 px, JPEG) — это держит запрос
намного меньше лимита serverless-функций (на Vercel Hobby ~4.5 МБ) и дешевле по API. Детекция
устойчива к ресайзу.

## Как работает лимит бесплатных проверок

Счётчик хранится в **подписанной httpOnly-cookie** (`<count>.<hmac>`), подпись — `QUOTA_SECRET`.
Клиент не может «подкрутить» число, чтобы сбросить пейволл. Проверка и инкремент — на сервере;
израсходованный лимит → **402** ещё до вызова платного API.

Это не «пуленепробиваемо»: очистка cookie или другой браузер/устройство обнуляют лимит. Для жёсткого
лимита — считать по авторизованному пользователю или по IP в KV-хранилище (Upstash / Vercel KV).

## Деплой (Vercel)

1. Залейте репозиторий на GitHub, импортируйте в Vercel (Next определится сам).
2. Добавьте переменные окружения из таблицы выше.
3. Deploy. Сжатие на клиенте уже решает вопрос лимита размера тела запроса.

Подойдёт любой Node-хостинг (`npm run build && npm start`) или Docker.

## Подключить свою модель (buy-then-build)

Когда ваша гибридная 2D/3D-модель будет за HTTP-эндпоинтом — реализуйте `ownModelDetect` в
`lib/detector.ts` и поменяйте одну строку:

```ts
export const detect = ownModelDetect; // было sightengineDetect
```

Форму `DetectionResult` сохраняйте — UI менять не нужно.

## Подключить оплату

Кнопка в `components/Paywall.tsx` открывает `NEXT_PUBLIC_CHECKOUT_URL`. Достаточно вставить готовую
ссылку (Stripe Payment Link / Lemon Squeezy / ЮKassa). Для полноценных подписок с автопродлением —
добавьте вебхук провайдера и выдачу доступа (тогда же имеет смысл перенести счётчик в БД).

## Ограничения MVP

- Только изображения (видео — позже).
- HEIC (айфонные фото) браузер часто не декодирует в canvas → пользователю предложат сохранить в
  JPEG. Для поддержки HEIC добавьте клиентский декодер (`heic2any`).
- Оценка вероятностная; на «диких» данных точность ниже бенчмарков. В UI намеренно показывается
  уверенность, а не бинарное «да/нет».
